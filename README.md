# 출퇴근 자동 체크 어플리케이션 (Attendance Tracker)

이 프로그램은 Windows 컴퓨터가 켜지면(로그인 시) 자동으로 **출근**, 컴퓨터가 꺼지면(종료/로그아웃 시) 자동으로 **퇴근**을 기록해 주는 전용 데스크톱 어플리케이션입니다.

---

## 📂 파일 구성
* **`AttendanceTracker.exe`**: C#으로 제작된 최종 실행 어플리케이션입니다. (트레이 상주형)
* **`AttendanceApp.cs`**: 어플리케이션의 C# 원본 소스 코드 파일입니다.
* **`build.ps1`**: 원본 소스 코드를 통해 실행 파일(`.exe`)을 다시 빌드하고 싶을 때 사용하는 파워쉘 스크립트입니다.

---

## ⚙️ 실행 및 자동 실행 등록 방법
프로그램 실행부터 컴퓨터를 켜고 끌 때 자동 체크되도록 설정하는 방법입니다.

1. **`AttendanceTracker.exe`** 파일을 더블클릭하여 실행합니다.
2. 실행하면 작업 표시줄 오른쪽 아래(시계 옆 시스템 트레이 영역)에 아이콘이 생성되며 백그라운드 구동을 시작합니다.
3. 트레이 아이콘을 **더블클릭**하거나, 마우스 우클릭 후 **[설정 및 로그 보기]**를 누르면 설정 창이 열립니다.
4. 설정 창에서 **"윈도우 켤 때 자동으로 앱 실행 (출퇴근 감지)"** 체크박스를 체크한 후 **[설정 저장]** 버튼을 클릭합니다.
5. 이제 컴퓨터를 켜고 끌 때마다 사용자가 수동으로 조작하지 않아도 알아서 출근과 퇴근이 체크됩니다.

---

## 🛠️ 제공 기능 및 설정 안내

1. **사원 이름 설정**:
   - 본인의 이름을 입력해 두면 로그 파일에 해당 이름으로 기록됩니다. (기본값은 윈도우 사용자 계정 이름)
2. **기록 저장 폴더 설정**:
   - 기본 경로는 `C:\Attendance`입니다.
   - 사내 공유 네트워크 폴더 경로(예: `\\ShareServer\AttendanceLog`)를 지정하면, 여러 명의 출퇴근 기록을 한 곳으로 통합하여 모을 수 있습니다.
3. **최근 출퇴근 기록 조회**:
   - 설정 창 하단에 있는 테이블에서 최근 100건의 기록을 실시간으로 편리하게 조회해 볼 수 있습니다.

---

## 📊 출퇴근 기록 CSV 포맷
출퇴근 내역은 지정하신 폴더의 `attendance_log.csv` 파일로 자동 기록되며, Microsoft Excel이나 메모장을 통해 한글 깨짐 없이 바로 열어보실 수 있습니다.

### 기록 예시:
| DateTime | Action | EmployeeName | ComputerName |
| :--- | :--- | :--- | :--- |
| 2026-08-27 09:00:15 | 출근 | 홍길동 | DESKTOP-ABC1234 |
| 2026-08-27 18:05:43 | 퇴근 | 홍길동 | DESKTOP-ABC1234 |

---

## ⚠️ 주의 및 트러블슈팅

* **백그라운드 감지**: 앱이 시스템 종료를 감지해야 하므로 수동으로 트레이 우클릭 -> [종료]를 눌러 끄면 컴퓨터 종료 시 퇴근 처리가 되지 않습니다. 항상 켜두셔야 정상 감지됩니다. (메모리 점유율 10MB 미만의 초경량 어플리케이션입니다.)
* **관리자 권한 관련**: 공유 네트워크 폴더나 특정 시스템 폴더에 기록할 경우, 해당 폴더에 일반 사용자의 쓰기 권한이 허용되어 있는지 확인해 주세요.
