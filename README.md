# 🌻 헬로굿바이 (출퇴근 자동 체크 시스템)

이 프로그램은 Windows 컴퓨터가 켜지면(로그인 시) 자동으로 **출근**, 컴퓨터가 꺼지면(종료/로그아웃 시) 자동으로 **퇴근**을 기록해 주는 데스크톱 어플리케이션입니다.

또한, 영업 현장이나 재택근무자를 위한 **스마트폰(모바일) 수동 입력** 및 관리자용 **실시간 통합 웹 대시보드와 사원별 엑셀 다운로드**를 완벽하게 지원합니다.

---

## 📂 파일 구성
* **`헬로굿바이.exe`**: C#으로 제작된 최종 실행 어플리케이션입니다. (해바라기 아이콘 적용)
* **`dashboard.html`**: 관리자용 실시간 출퇴근 관리 웹 대시보드 소스입니다.
* **`index.html`**: 직원용 웹 다운로드 페이지 소스입니다.
* **`AttendanceApp.cs`**: 헬로굿바이 어플의 C# 원본 소스 코드 파일입니다.
* **`build.ps1`**: 원본 소스 코드를 빌드하여 `헬로굿바이.exe`를 컴파일해 주는 빌드 스크립트입니다.

---

## ⚙️ 실행 및 자동 실행 등록 방법
1. **`헬로굿바이.exe`** 파일을 더블클릭하여 실행합니다. (트레이 영역에 해바라기 🌻 아이콘 생성)
2. 트레이 아이콘을 **더블클릭**하거나, 마우스 우클릭 후 **[설정 및 로그 보기]**를 누르면 설정 창이 열립니다.
3. 설정 창에서 **"윈도우 켤 때 자동으로 앱 실행 (출퇴근 감지)"** 체크박스를 체크한 후 **[설정 저장]** 버튼을 클릭합니다.

---

## 🖥️ 관리자 실시간 웹 대시보드 사용법 (한눈에 보기 & 엑셀 다운로드)
직원들이 스마트폰(모바일)이나 PC 어플로 등록하는 모든 출퇴근 기록을 실시간으로 한눈에 보고 사원별 엑셀로 추출하는 방법입니다.

### 1단계: 구글 스프레드시트 공유 권한 열기
어플과 대시보드가 구글 시트의 데이터를 읽을 수 있도록 권한을 설정해야 합니다. (수정 권한이 아닌 읽기 권한만 여는 것이라 안전합니다.)
1. 구글 설문지와 연동된 **구글 스프레드시트**를 엽니다.
2. 화면 우측 상단의 **[공유]** 버튼을 클릭합니다.
3. 아래의 일반 액세스에서 권한을 **"링크가 있는 모든 사용자"**로 변경하고, 우측 역할은 **"뷰어"**로 그대로 둡니다.
4. 웹 브라우저 주소창의 주소 전체(예: `https://docs.google.com/spreadsheets/d/XXXXXXXX/edit...`)를 복사해 둡니다.

### 2단계: 웹 대시보드 접속 및 연동
1. 본인의 Vercel 홈페이지 주소 뒤에 `/dashboard.html`을 붙여서 인터넷 브라우저로 접속합니다.
   - 예시: `https://[프로젝트명].vercel.app/dashboard.html`
2. 데이터 연동 설정 칸에 복사해 둔 **구글 스프레드시트 URL 전체 주소**를 붙여넣고 **[연동 및 불러오기]**를 누릅니다.
   - *로컬 브라우저에 저장되므로 최초 1회만 입력하시면 됩니다.*
3. 연동이 완료되면 오늘 출퇴근한 사원 수 통계와 함께 실시간 출퇴근 목록이 표 형태로 한눈에 들어옵니다.

### 3단계: 사원별 엑셀 다운로드
1. 대시보드의 **`사원명 검색`** 입력창에 원하는 직원의 이름을 입력합니다. (입력 즉시 실시간 필터링 적용)
2. 우측의 초록색 **[필터링된 사원 기록 엑셀 다운로드]** 버튼을 클릭합니다.
3. 해당 사원의 출퇴근 데이터만 쏙 필터링된 엑셀(CSV) 파일이 즉시 컴퓨터로 다운로드됩니다. (BOM 인코딩 적용으로 한글 깨짐 전혀 없음)

## 📱 현장 영업사원을 위한 스마트폰(모바일) 앱 아이콘 설정 방법
사외 현장이나 직출/직퇴 시, 스마트폰 바탕화면(홈 화면)에 진짜 어플 아이콘처럼 등록하여 터치 한 번으로 출퇴근을 찍을 수 있는 방법입니다.

### 🤖 갤럭시 (안드로이드) 설정 방법
1. 카카오톡 등으로 공유받은 **구글 설문지(Google Forms) 웹 링크**를 터치하여 크롬(Chrome) 브라우저로 엽니다.
2. 우측 상단의 **[점 3개(메뉴)]** 버튼을 클릭합니다.
3. 목록에서 **[홈 화면에 추가]** 또는 **[현재 페이지 추가 -> 홈 화면]**을 선택합니다.
4. 이름(예: "출퇴근 체크")을 입력하고 추가하면, 바탕화면에 앱 아이콘이 바로 생성됩니다.

### 🍎 아이폰 (iOS) 설정 방법
1. 구글 설문지 웹 링크를 **Safari(사파리) 브라우저**로 엽니다.
2. 화면 하단 중앙의 **[공유 버튼(네모 상자에 위쪽 화살표 모양)]**을 터치합니다.
3. 메뉴를 아래로 스크롤하여 **[홈 화면에 추가]**를 클릭합니다.
4. 이름(예: "출퇴근 체크")을 입력하고 우측 상단의 [추가]를 누르면, 바탕화면에 앱 아이콘이 생성됩니다.
