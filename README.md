# 출퇴근 자동 체크 어플리케이션 (Attendance Tracker)

이 프로그램은 Windows 컴퓨터가 켜지면(로그인 시) 자동으로 **출근**, 컴퓨터가 꺼지면(종료/로그아웃 시) 자동으로 **퇴근**을 기록해 주는 데스크톱 어플리케이션입니다.

또한, 영업 현장이나 재택근무자를 위해 **스마트폰(모바일) 수동 입력** 및 **구글 스프레드시트 실시간 통합 수집**을 완벽하게 지원합니다.

---

## 📂 파일 구성
* **`AttendanceTracker.exe`**: C#으로 제작된 최종 실행 어플리케이션입니다.
* **`AttendanceApp.cs`**: C# 원본 소스 코드 파일입니다.
* **`build.ps1`**: 소스 코드를 실행 파일(`.exe`)로 다시 컴파일해 주는 빌드 스크립트입니다.
* **`index.html`**: Vercel 연동 다운로드용 웹페이지 소스입니다.

---

## ⚙️ 실행 및 자동 실행 등록 방법
1. **`AttendanceTracker.exe`** 파일을 더블클릭하여 실행합니다. (트레이 영역에 아이콘 생성)
2. 트레이 아이콘을 **더블클릭**하거나, 마우스 우클릭 후 **[설정 및 로그 보기]**를 누르면 설정 창이 열립니다.
3. 설정 창에서 **"윈도우 켤 때 자동으로 앱 실행 (출퇴근 감지)"** 체크박스를 체크한 후 **[설정 저장]** 버튼을 클릭합니다.

---

## 📊 구글 스프레드시트 실시간 통합 설정 (관리자용)
영업 사원이 사외에서 등록한 모바일 기록과 사내 PC 자동 기록을 한곳으로 모으기 위한 설정법입니다.

1. 동봉된 **[구글 폼 연동 가이드라인(google_form_setup.md)](file:///C:/Users/admin/.gemini/antigravity/brain/826df906-6f76-4062-84ed-7811d49f4818/google_form_setup.md)**에 따라 구글 설문지를 개설합니다.
2. 설문지에서 추출한 **`구글 폼 ID`**와 3가지 **`Entry ID`** 값을 어플리케이션 설정 창의 **[구글 스프레드시트 실시간 연동 (선택사항)]** 그룹박스에 정확히 입력합니다.
3. **[설정 저장]**을 누르면 모든 세팅이 완료되며, 이후부터 인터넷망을 통해 구글 스프레드시트에 출퇴근 시간이 실시간으로 누적됩니다.
   - *팁: 관리자님 PC에서 이 설정을 마친 뒤, 다시 `build.ps1`을 실행하면 해당 설정값이 아예 기본으로 고정 탑재된 EXE 파일로 새로 빌드됩니다. 이 빌드된 파일을 직원들에게 배포하면 직원들은 어떠한 설정 주소도 입력할 필요 없이 이름만 쓰고 바로 쓸 수 있습니다!*

## 📱 현장 영업사원을 위한 스마트폰(모바일) 앱 아이콘 설정 방법
외근이나 현장 직출/직퇴 시, 스마트폰 바탕화면(홈 화면)에 진짜 어플 아이콘처럼 등록하여 터치 한 번으로 출퇴근을 찍을 수 있는 방법입니다.

### 🤖 갤럭시 (안드로이드) 설정 방법
1. 카카오톡 등으로 공유받은 **구글 설문지(Google Forms) 웹 링크**를 터치하여 실행합니다.
2. 우측 상단의 **[점 3개(메뉴)]** 버튼을 클릭합니다.
3. 목록에서 **[홈 화면에 추가]** 또는 **[현재 페이지 추가 -> 홈 화면]**을 선택합니다.
4. 이름(예: "출퇴근 체크")을 입력하고 추가하면, 바탕화면에 파란색 체크마크 앱 아이콘이 바로 생성됩니다.

### 🍎 아이폰 (iOS) 설정 방법
1. 구글 설문지 웹 링크를 **Safari(사파리) 브라우저**로 엽니다.
2. 화면 하단 중앙의 **[공유 버튼(네모 상자에 위쪽 화살표 모양)]**을 터치합니다.
3. 메뉴를 아래로 스크롤하여 **[홈 화면에 추가]**를 클릭합니다.
4. 이름(예: "출퇴근 체크")을 입력하고 우측 상단의 [추가]를 누르면, 바탕화면에 앱 아이콘이 생성됩니다.

> [!TIP]
> 이제 외근 중일 때 스마트폰 바탕화면에 생성된 **"출퇴근 체크"** 아이콘만 누르면 즉시 구글 폼이 켜집니다. 사원 이름과 출근/퇴근 구분만 터치해서 제출하면 관리자님의 구글 시트에 실시간으로 취합됩니다.
