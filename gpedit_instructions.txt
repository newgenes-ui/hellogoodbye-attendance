[Windows Pro 이상 사용자 대상: 로컬 그룹 정책 편집기를 활용한 출퇴근 체크 설정 안내]

본 안내서는 Windows Pro, Enterprise, Education 에디션을 사용하는 환경에서 Windows 작업 스케줄러 대신 '로컬 그룹 정책'의 컴퓨터 시작/종료 스크립트 기능을 이용하여 더욱 강력하고 안정적으로 출퇴근을 체크하는 방법입니다. (Windows Home 버전은 이 기능을 지원하지 않으므로 기본 제공되는 install.ps1 스크립트를 통한 작업 스케줄러 등록 방식을 그대로 이용하시면 됩니다.)

--------------------------------------------------
■ 1단계: 로컬 그룹 정책 편집기 실행
--------------------------------------------------
1. 키보드의 [Windows 로고 키 + R]을 눌러 실행 창을 엽니다.
2. 입력창에 `gpedit.msc` 를 입력하고 엔터를 누릅니다.

--------------------------------------------------
■ 2단계: 출근(부팅 시) 스크립트 등록
--------------------------------------------------
1. 왼쪽 트리 메뉴에서 아래 경로로 이동합니다.
   [컴퓨터 구성] -> [Windows 설정] -> [스크립트(시작/종료)]
2. 오른쪽 목록에서 [시작] 항목을 더블 클릭하여 속성 창을 엽니다.
3. [추가(A)...] 버튼을 클릭합니다.
4. 아래와 같이 입력합니다:
   - 스크립트 이름(N): `powershell.exe`
   - 스크립트 매개변수(P): `-NoProfile -ExecutionPolicy Bypass -File "C:\Attendance\check_attendance.ps1" -Action ON`
5. [확인]을 누르고, 시작 속성 창에서도 [확인] 또는 [적용]을 누릅니다.

--------------------------------------------------
■ 3단계: 퇴근(시스템 종료 시) 스크립트 등록
--------------------------------------------------
1. 동일하게 [스크립트(시작/종료)] 메뉴에서 오른쪽의 [종료] 항목을 더블 클릭합니다.
2. [추가(A)...] 버튼을 클릭합니다.
3. 아래와 같이 입력합니다:
   - 스크립트 이름(N): `powershell.exe`
   - 스크립트 매개변수(P): `-NoProfile -ExecutionPolicy Bypass -File "C:\Attendance\check_attendance.ps1" -Action OFF`
4. [확인]을 누르고, 종료 속성 창에서도 [확인] 또는 [적용]을 누릅니다.

--------------------------------------------------
■ 참고 사항 (주의)
--------------------------------------------------
※ 스크립트 매개변수에 들어가는 경로("C:\Attendance\...")에 해당 스크립트 파일들이 실제로 저장되어 있어야 정상 작동합니다. (`install.ps1`을 먼저 1회 실행하면 파일들이 해당 경로로 자동 복사됩니다.)
※ 그룹 정책으로 등록하는 경우, 백그라운드 모니터 스크립트(attendance_monitor.ps1)를 실행해 둘 필요가 없으므로 작업 스케줄러에 등록된 `Attendance_Check_System` 작업은 삭제하거나 사용 안 함으로 설정하셔도 무방합니다.
